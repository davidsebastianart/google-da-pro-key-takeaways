## Key Takeaways (Functions)

- **Define functions and return values**
	- **Defining Functions**
		- Functions are reusable blocks of code designed to perform specific tasks.
		- To define a function in Python, use the keyword "def," followed by the function name, parameters in parentheses, a colon, and an indented body.
	
	- **Using Functions and Parameters**
		- Functions can take parameters (arguments) to customize their behavior; these parameters are specified in parentheses after the function name.
		- The function body contains indented code that executes when the function is called, and parameters are referenced within this body.
	
	- **Return Values and Code Reusability**
		- The "return" keyword allows a function to output a value that can be stored and used later, rather than just printing it.
		- Returning values enables combining function calls with other operations, promoting code reuse and efficiency in programming tasks.

- **Write clean code**
	- **Code Reusability**
		- Reusability means defining code once and using it multiple times without rewriting.
		- Using functions helps eliminate code duplication, making scripts cleaner and easier to maintain.
	
	- **Modularity in Python**
		- Modularity involves writing code in separate components that work together and can be reused.
		- Python's modular nature supports collaboration by allowing reuse of code blocks in larger projects.
	
	- **Code Clarity and Refactoring**
		- Refactoring restructures code to improve readability while keeping functionality intact.
		- Writing self-documenting code with clear variable names and comments helps others understand and reuse the code effectively.

- **Use comments to scaffold your code**
	- **Understanding Algorithms and Thinking Algorithmically**
		- An algorithm is a set of instructions to solve a problem or complete a task, similar to a recipe.
		- Thinking algorithmically means logically explaining steps to a computer, which is essential for programming.
	
	- **Writing Functions with Comments**
		- Functions are algorithms in code; breaking them into small steps with comments helps clarify the problem.
		- Comments act as scaffolding, outlining each step before coding, making complex tasks manageable.
	
	- **Creating User-Friendly Functions with Docstrings**
		- A docstring is a descriptive string at the start of a function explaining its purpose, parameters, and return values.
		- Well-documented code with comments and docstrings improves readability and usability for yourself and others.

## Key Takeaways (Conditional statements)

- **Boolean Data and Comparators**
	- Boolean data has only two values: True or False, named after mathematician George Boole.
	- Comparators compare two values and return Boolean results, such as greater than, less than, equal to, and not equal to.
	
	- **Logical Operators in Python**
		- Logical operators like and, or, and not combine multiple Boolean expressions for complex comparisons.
		- The and operator returns True only if both expressions are true; or returns True if at least one expression is true; not inverts the Boolean value.
	
		- **Practical Use and Examples**
		- Comparators can be used with numbers and strings, where string comparison is based on alphabetical order.
		- Logical operators help data professionals write complex code to control program flow and data decisions effectively.

- **Use if, elif, else statements to make decisions**
	- **Branching with IF and ELSE**
		- IF statements allow a program to execute certain code only when a specified condition is True.
		- ELSE statements provide an alternative set of instructions when the IF condition is False, enabling two possible paths in the code.
	
	- **Using the Modulo Operator and Returning Values**
		- The modulo operator (%) returns the remainder of a division, useful for conditions like checking if a number is even.
		- IF statements can return values directly, and an ELSE statement is optional if the function returns a value after the IF block.
	
	- **Extending Conditions with ELIF**
		- ELIF (else-if) allows checking multiple conditions sequentially without deep nesting of IF-ELSE blocks.
		- This makes code easier to read and manage when there are more than two possible conditions to evaluate.
